description: Scope-and-rank phase only — design the levels, delegate nothing
---

Run only the **scope** phase of the inception workflow — no agents, no delegation, no edits. You are The Architect drawing the maze before anyone goes under.

Read the tree, measure, count usages. Produce a **ranked findings list**, biggest value-per-effort first. Pure deletions rank above refactors — they're CI-verifiable and carry zero design risk. For each finding give one line: what to do, why it's worth it, rough effort, and which level would own it (**L0 Architect** = you keep it; **L1 Forger** = judgment executor; **L2 Point Man** = mechanical executor).

End with the shape of the levels: which findings could run as concurrent agents, and where their file scopes need fencing so no two collide. Stop there — don't go under.
